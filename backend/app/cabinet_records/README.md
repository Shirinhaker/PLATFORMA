# Cabinet records

Bu paket V7 migratsiyasidan keyin `cabinet_payload` ichida vaqtincha qolgan haqiqiy ma’lumotlarni relational record/field jadvallariga ko‘chirish uchun ishlatiladi.

Relational qatlam nested list/object qiymatlarni JSON blob sifatida saqlamaydi. Har bir top-level resource yozuvi alohida record, har bir scalar leaf esa typed field qatori bo‘ladi.
